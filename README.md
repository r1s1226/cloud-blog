# 클라우드 프로그래밍 학습 포트폴리오

한 학기 동안 수강한 **클라우드 프로그래밍** 수업의 학습 내용과 실습 과정을 주차별로 정리한 기술 블로그입니다. AWS · Docker · Kubernetes 를 다룹니다.

🔗 **블로그:** https://r1s1226.github.io/cloud-blog/

## 로컬에서 보기

```bash
python -m http.server 8099
# 브라우저에서 http://localhost:8099
```

## 구조

- `index.html` · `posts/` — 블로그 페이지
- `_content/*.md` — 글 원본 (수정 후 `python build.py` 로 재생성)
- `assets/` — 스타일(CSS) · 이미지
