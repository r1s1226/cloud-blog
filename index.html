클라우드 프로그래밍 학습 기록 — AWS · Docker · Kubernetes

한 학기 동안 클라우드 프로그래밍 수업에서 배운 내용과 직접 따라 한 실습 과정을 주차별로 정리한 학습 포트폴리오입니다.

수업은 클라우드의 기본 개념에서 출발해 AWS(EC2·VPC) → Docker(컨테이너·이미지·컴포즈) → Kubernetes(파드부터 RBAC·오퍼레이터까지) 로 이어졌습니다. 각 글에는 ① 개념 정리, ② 실습 과정(명령어·설정), ③ 실습 중 만난 문제와 해결 방법, ④ 회고를 담았습니다.

실습 환경: Windows 11 + VMware/Ubuntu, Docker Desktop, Rancher Desktop·K3s 기반 단일 노드 쿠버네티스. 예제는 『AWS 교과서』(길벗)와 Learn Docker / Kubernetes in a Month of Lunches(diamol·kiamol)를 따랐습니다.
